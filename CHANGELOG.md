## [0.1.0] - 2026-10-25

Этап 1: каркас приложения.

### Added

- Пакет `chimera/` (core, models, services, web), Flask 3 + SQLAlchemy 2 +
  Alembic; PostgreSQL 16 на сервере и SQLite в режиме `desktop-local`.
- Типизированная конфигурация из окружения и `.env`; в desktop-режиме ключи
  создаются и сохраняются в каталоге данных автоматически.
- Шифрование отдельных полей (`EncryptedString`, Fernet, ротация ключей) и
  слепой индекс HMAC-SHA256 для поиска по точному значению.
- Организации (вуз/колледж) с реквизитами и дерево подразделений
  «организация → факультет/отделение → кафедра/цикловая комиссия».
- Централизованная изоляция организаций: ORM-фильтр для всех моделей
  организации, проверка при сохранении, тесты на утечку.
- Пользователи, членства в нескольких организациях, роли `admin`, `head`,
  `curator`, `starosta`, `viewer` с декларативной матрицей прав; системный
  администратор для управления организациями и резервными копиями.
- Переключатель организации в шапке.
- Режим «работать как» для администратора (руководитель подразделения,
  куратор, староста) с плашкой и аудитом каждого действия с реальной ролью.
- Вход, выход, смена пароля, обязательная смена пароля при первом входе,
  начальный администратор из `ADMIN_DEFAULT_PASSWORD`, ограничение попыток
  входа, саморегистрация с одобрением администратором.
- Журнал аудита (было/стало, скрытие зашифрованных полей) с фильтрами и поиском.
- Резервные копии: копия SQLite с проверкой целостности или `pg_dump`
  с понятным сообщением, если программа не найдена; проверка версии схемы.
- Словарь терминологии `chimera/core/terms.py` и фича-флаги
  `chimera/core/features.py` с бейджами «Скоро»/«Бета».
- Оболочка интерфейса в стиле Manticore: тёмный сайдбар, светлая/тёмная тема,
  адаптивность до планшета, печатные стили, CSP без inline-скриптов.
- CI (ubuntu + windows, тесты на SQLite и PostgreSQL 16, `alembic check`),
  workflow безопасности (gitleaks, pip-audit), Dependabot, pre-commit.
- Docker-образ с LibreOffice и шрифтами, docker-compose (app + PostgreSQL +
  nginx), примеры systemd и nginx.
- Документация: установка, развёртывание, роли, безопасность, структура,
  правила разработки.
