# Дополнительные шрифты

Файлы `.ttf`/`.otf` из этой папки копируются в образ (`/usr/local/share/fonts/chimera`)
и используются LibreOffice при конвертации документов в PDF.

Образ уже содержит DejaVu, Liberation (метрически совместим с Times New Roman, Arial,
Courier New), Carlito/Caladea (совместимы с Calibri/Cambria) и PT Serif/Sans/Mono.
Если шаблоны организации используют **PT Astra Serif**, скачайте его с сайта
ParaType (свободная лицензия OFL) и положите файлы сюда перед сборкой образа.
