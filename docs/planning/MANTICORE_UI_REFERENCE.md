# Этап 01. UI-референс Manticore для Chimera

Сравнение выполнено по Manticore `0e9e5d7` и Chimera `8da65b7` от 22.11.2026. Идентификаторы и состояние функций приведены в [матрице переноса](MANTICORE_FEATURE_PARITY.md). Этот документ описывает проверенные в исходниках компоненты, различия и ожидаемое поведение при будущей приёмке. Визуальная проверка в браузере и реальный Windows WebView2 — **NOT TESTED** на этапе 01.

## Ручная приёмка после реализации

Все действия выполняются с синтетическими записями. Базовый набор — две организации, две группы, одноимённые люди, отдельные роли администратора, куратора и наблюдателя, в том числе человек с параллельными обучениями. Для проверки форматов нужны локальные синтетические CSV/XLSX/DOCX/PDF.

| Режим и этапы | Действие | Принимаемый результат |
|---|---|---|
| Общий веб и Desktop, 03–05 | Перейти с клавиатуры от входа к главной и из меню в профиль. На узком экране открыть навигацию, пройти табуляцией, открыть диалог, закрыть Escape. Повторить с тремя темами и масштабом 200%. | Фокус виден и возвращается, активный раздел очевиден, текст читается, управляющие элементы доступны, контент не перекрыт. Тема сохраняется после перезапуска. |
| SQLite и PostgreSQL, 25, 29–30, 39–40 | Ввести кириллицу и быстро сменить запросы, открыть поиск Ctrl+K, выбрать несколько групп и строки.
