# Chimera: контрольный список выпуска

Публикация запрещена, пока каждый обязательный пункт не отмечен. Все проверки
с отказами выполняются только на тестовых данных.

## Автоматические проверки

- [ ] CI зелёный: ubuntu (SQLite + PostgreSQL 16) и windows (SQLite)
- [ ] `ruff check .`, `ruff format --check .`, `mypy`
- [ ] `alembic check` без неучтённых изменений моделей
- [ ] Workflow `security`: gitleaks и pip-audit без находок
- [ ] `python sync_app_metadata.py --check`
- [ ] `git diff --check`

## Версия и документация

- [ ] `VERSION` обновлён, раздел в `CHANGELOG.md` перенесён из `[Unreleased]`
- [ ] Документация в `docs/` соответствует поведению
- [ ] Незавершённые модули помечены фича-флагами и бейджами в интерфейсе

## Установка и миграции

- [ ] Чистая установка через Docker Compose
- [ ] Обновление с предыдущего выпуска: копия базы → `python -m chimera migrate`
- [ ] Downgrade миграции на копии базы
- [ ] Старая версия отказывается запускаться на более новой схеме
- [ ] Резервная копия создана и восстановлена на отдельном сервере

## Безопасность

- [ ] Изоляция организаций: вход администратором второй организации, попытка
      открыть чужие записи по прямым ссылкам
- [ ] Режим «работать как»: плашка, ограничение прав, записи в журнале
- [ ] Вход с неверным паролем ограничивается после заданного числа попыток
- [ ] CSP: в консоли браузера нет нарушений
- [ ] Зашифрованные поля не читаются в базе в открытом виде

## Интерфейс

- [ ] Светлая и тёмная тема
- [ ] Ширина планшета (768–1024 px)
- [ ] Терминология для вуза и для колледжа
- [ ] Печать страниц-ведомостей
