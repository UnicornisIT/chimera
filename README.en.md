# Chimera

Chimera is a workspace for **study group curators** at Russian universities and
colleges. Student data is entered once and reused to assemble routine documents:
student dossiers, character references, attendance sheets, explanatory notes,
academic committee minutes, curator hour plans, duty and cleaning rosters,
dormitory inspection sheets and reports.

Chimera is a sibling of [Manticore](https://github.com/UnicornisIT/manticore)
(an admissions office application): same look and feel, same infrastructure and
compatible accounts, so both can later share a single launcher.

> **Status: alpha.** The foundation is ready: organizations, divisions, users and
> roles, audit log, backups and field-level encryption. Groups, students and
> documents arrive in the next stages and are marked "Soon" in the UI. The
> application handles personal data: do not expose it directly to the internet,
> use HTTPS/VPN and verify backup restore before going live.

## Features

- multiple organizations per installation with strict data isolation enforced
  in the service layer;
- terminology adapted to the organization type (university or college);
- roles: administrator, division head, curator, group leader (starosta), viewer;
  one user may work in several organizations;
- "act as" mode for administrators with a visible banner and every action audited;
- audit log (who, in which role, what, before/after) with filters and search;
- field-level encryption (Fernet) and blind indexes for exact-match lookups;
- self-registration with admin approval, forced password change, login rate
  limiting, CSRF protection, CSP without inline scripts;
- PostgreSQL 16 on the server, SQLite in local mode; Alembic migrations;
- backups: SQLite file copy or `pg_dump`;
- light and dark themes, tablet-friendly layout, print styles.

## Quick start

CPython 3.11 is required.

```bash
cp .env.example .env   # set SECRET_KEY, DATA_ENCRYPTION_KEY, POSTGRES_PASSWORD, ADMIN_DEFAULT_PASSWORD
docker compose -f deploy/docker-compose.yml --env-file .env up -d --build
```

For a local run from source:

```bash
python3.11 -m venv .venv
.venv/bin/python -m pip install -e ".[dev]"
.venv/bin/python -m chimera migrate
.venv/bin/python -m chimera run
```

The documentation in [`docs/`](docs/) is written in Russian.
