# Chimera

Chimera — рабочее место **куратора учебной группы** вуза или колледжа. Данные о
студентах вводятся один раз, а из них собираются типовые документы: досье,
характеристики, ведомости посещаемости, объяснительные, протоколы УВК,
кураторские часы, графики дежурств и уборки, ведомости проверки общежитий и
отчёты.

Chimera — «сестра» [Manticore](https://github.com/UnicornisIT/manticore)
(приложения для приёмной комиссии): тот же внешний вид, та же инфраструктура и
совместимые учётные записи, чтобы в будущем объединить оба приложения в общий
лаунчер.

> **Статус: alpha.** Готов каркас: организации, подразделения, пользователи и
> роли, журнал аудита, резервные копии и шифрование полей. Группы, студенты и
> документы появятся на следующих этапах — в интерфейсе они помечены «Скоро».
> Приложение работает с персональными данными (152-ФЗ): не публикуйте его
> напрямую в интернет, используйте HTTPS/VPN и проверьте восстановление из
> резервной копии до начала работы.

## Возможности

- несколько организаций в одной установке (вузы и колледжи), строгая изоляция
  данных между ними на уровне сервисного слоя;
- терминология под тип организации: факультет/отделение, кафедра/цикловая
  комиссия, направление подготовки/специальность и т. д.;
- роли: администратор, руководитель подразделения, куратор, староста,
  наблюдатель; один пользователь может работать в нескольких организациях;
- режим «работать как» для администратора с заметной плашкой и записью
  каждого действия в аудит;
- журнал аудита «кто, в какой роли, что, было/стало» с фильтрами и поиском;
- шифрование отдельных полей (Fernet) и «слепой индекс» для поиска по точному
  значению (СНИЛС, паспорт);
- саморегистрация с одобрением администратором, принудительная смена пароля,
  ограничение попыток входа, CSRF, CSP без inline-скриптов;
- PostgreSQL 16 на сервере и SQLite в локальном режиме; миграции Alembic;
- резервные копии: файл SQLite или `pg_dump`;
- светлая и тёмная тема, адаптивность до планшета, печатные стили.

## Быстрый старт

Требуется CPython 3.11.

### Docker Compose (сервер)

```bash
cp .env.example .env   # задайте SECRET_KEY, DATA_ENCRYPTION_KEY, POSTGRES_PASSWORD, ADMIN_DEFAULT_PASSWORD
docker compose -f deploy/docker-compose.yml --env-file .env up -d --build
```

Откройте `http://localhost`, войдите как `admin` и смените пароль.

### Локально из исходников

```bash
python3.11 -m venv .venv
.venv/bin/python -m pip install -e ".[dev]"
cp .env.example .env    # для разработки достаточно CHIMERA_MODE=desktop-local
.venv/bin/python -m chimera migrate
.venv/bin/python -m chimera run
```

На Windows используйте `py -3.11 -m venv .venv` и `.venv\Scripts\python.exe`.
Подробности — в [инструкции по установке](docs/installation.md).

## Структура проекта

```text
chimera/
  core/        общий с Manticore код: конфиг, БД, права, аудит, терминология, шифрование
  models/      ORM-модели по доменам
  services/    бизнес-логика без Flask
  web/         Blueprints: тонкие роуты
  templates/   Jinja-шаблоны
  static/      стили, скрипты, изображения
migrations/    Alembic
deploy/        Docker, nginx, systemd
tests/         pytest (SQLite и PostgreSQL)
```
